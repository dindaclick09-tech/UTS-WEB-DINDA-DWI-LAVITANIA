# Portofolio Dinda Dwi Lavitania

Website portofolio pribadi untuk memperkenalkan profil, pengalaman, karya, dan proyek Dinda Dwi Lavitania, mahasiswa Sistem Informasi di Universitas Nusantara PGRI Kediri.

## Fitur

- Profil, biodata, riwayat pendidikan, pengalaman kerja, dan minat.
- Galeri foto prestasi, panggung, latte art, dan crafting. Klik foto untuk membukanya dalam ukuran penuh.
- Showcase proyek.
- Kalkulator estimasi biaya pembuatan website.
- Tombol dark mode.
- Formulir kontak dengan validasi dan notifikasi demo.
- Animasi saat bagian halaman muncul ketika di-scroll.

## Teknologi

- HTML5
- CSS3
- Bootstrap 5.3.2
- JavaScript
- Font Awesome 6.4.2

Bootstrap dan Font Awesome dimuat dari CDN, sehingga koneksi internet diperlukan agar aset tersebut dapat ditampilkan.

## Menjalankan Website

1. Unduh atau clone repositori ini.
2. Buka folder `UTS-WEB-DINDA DWI LAVITANIA`.
3. Buka `index.html` di browser.

Website ini merupakan halaman statis dan tidak memerlukan instalasi atau server khusus. Formulir kontak hanya menampilkan validasi dan notifikasi di halaman; formulir belum mengirim pesan ke email atau server.
